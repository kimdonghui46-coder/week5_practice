WEEK 5 · CAPSTONE PROJECT

GameGearMatch

게임 장르와 사용자 선호를 반영한 게이밍 기어 추천 쇼핑몰

누적 조회수 0

프로젝트 소개

GameGearMatch는 사용자가 주로 즐기는 게임 장르와 예산, 연결 방식 등의 선호 조건을 입력하면 적합한 마우스, 키보드, 헤드셋 등의 게이밍 기어를 추천해주는 맞춤형 웹 쇼핑몰입니다.

주요 기능

  • 게임 장르와 사용자 선호 조건을 반영한 상품 추천
  • Rule-Based Filtering을 이용한 필수 조건 상품 필터링
  • WSM을 이용한 상품별 추천 점수 및 순위 계산
  • 상품 조회, 장바구니, 주문 및 리뷰 기능 제공

추천 방식

  • 예산, 재고, 연결 방식 등 필수 조건 확인
  • 조건에 맞지 않는 상품을 먼저 제외
  • 게임 장르별 가중치를 적용하여 적합도 계산
  • 점수가 높은 상품 순으로 사용자에게 추천

사용 기술

React와 TypeScript를 이용해 사용자 화면을 구성하고, Java와 Spring Boot를 이용해 백엔드 기능을 구현합니다. MySQL을 데이터베이스로 사용하며 AWS EC2, RDS, S3 등을 이용해 클라우드 환경에 배포하는 것을 목표로 합니다.
